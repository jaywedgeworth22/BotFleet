Automatic updates are designed for macOS and Windows; Ubuntu packages are updated by installing a newly downloaded package.  Today the [current release](https://github.com/jaywedgeworth22/botfleet-releases/releases/latest) carries macOS installers but not the `latest-mac.yml` feed the updater reads, so **Check for updates** cannot find anything yet.  Until a release ships with its feed files, install newer builds by downloading them.

## The download keeps spinning

Leave the app open long enough for one complete attempt, then quit and reopen it.  A failed differential update should fall back to the full package.  If the same release remains stuck, download the current installer from the [official releases repository](https://github.com/jaywedgeworth22/botfleet-releases/releases/latest) and install it over the existing copy.

## Restart to update does nothing

Quit BotFleet completely and launch it again. If the version did not change, install the latest release manually. Your conversations and settings live outside the application bundle and are not removed by replacing the app.

## Verify the installed version

Open **App settings** and check the displayed version. A commit merged to `main` is not in the desktop app until a release workflow publishes a new version.

<Callout type="warn" title="Use official artifacts">
  Do not install update files forwarded through chat or uploaded to an unrelated repository.  Use the [BotFleet releases repository](https://github.com/jaywedgeworth22/botfleet-releases/releases) and its checksums.
</Callout>
